# Descubre Cochabamba - versión mejorada

Funciones incluidas:
- Buscador con filtrado en tiempo real.
- Categorías con estado activo.
- Fichas completas de destinos en modal.
- Información de ubicación, tiempo, costo y valoración.
- Agregar/quitar destinos del recorrido.
- Recorridos recomendados.
- Guardado del recorrido en localStorage.
- Formulario de reservas con validación básica y código de confirmación.
- Navegación responsive y footer completo.

Para usar:
1. Abre index.html en Visual Studio Code o con Live Server.
2. No requiere instalación de librerías.
3. Para una reserva real conectada a una base de datos, habría que conectar el formulario a un backend o servicio de formularios.
